# Medical Dashboard
A modern medical dashboard built using React to manage patients, doctors, and appointments.
##  Features
- Add, delete, and manage patients
- Manage doctors and their specialties
- Create and delete appointments
- Dynamic updates using React state
- Clean and modern dark UI

##  Languages
- React (JavaScript)
- CSS
- HTML (JSX)

 ##  Note
This project uses fake data and runs entirely on the frontend.
